Politique de Confidentialité

Dernière mise à jour : 01/03/2026 — Version 1.0

1. Introduction

Avant de Répondre est une application mobile qui vous aide à détecter les arnaques dans vos emails, SMS et alertes à l'écran.

Cette politique explique comment nous collectons, utilisons et protégeons vos données personnelles.

2. Données Collectées

2.1 Données que vous nous envoyez

  • Contenu des emails transférés pour analyse
  • Contenu des SMS copiés-collés pour analyse
  • Photos d'alertes prises pour analyse
  • Votre adresse email (pour créer votre compte et vous envoyer les résultats)
  • Numéro de téléphone de l'expéditeur (optionnel, pour les SMS)

2.2 Données que nous ne collectons PAS

❌ Pas de nom ou prénom

❌ Pas de localisation

❌ Pas d'historique de navigation

❌ Pas de cookies ou trackers

❌ Pas de contenu de vos messages conservé après analyse

3. Utilisation des Données

Vos données sont utilisées uniquement pour :

  • Créer et gérer votre compte utilisateur
  • Suivre votre quota de vérifications gratuites
  • Analyser le message avec notre IA (Anthropic Claude) pour détecter les arnaques
  • Vous renvoyer le résultat par email (pour les emails transférés)

⚠️ Le contenu de vos messages (emails, SMS, photos) est supprimé immédiatement après analyse. Nous ne conservons aucun historique de vos messages.

4. Partage des Données

Anthropic (API Claude)

Rôle : Analyse IA du contenu
Localisation : États-Unis
Conformité : EU-US Data Privacy Framework, DPA signé

Firebase (Google)

Rôle : Authentification et gestion des comptes
Localisation : Union Européenne
Conformité : Conforme RGPD

Firebase Functions (Google)

Rôle : Réception et traitement automatique des emails transférés
Localisation : Union Européenne
Conformité : Conforme RGPD

Aucune revente ou partage commercial de vos données.

11. Questions Fréquentes

Stockez-vous mes emails/SMS ?

Non. Ils sont supprimés immédiatement après analyse (moins d'1 minute).

Vendez-vous mes données ?

Non. Jamais. Aucune revente, aucun partage commercial.

Comment supprimer mon compte ?

Dans l'application : Paramètres → Supprimer mon compte. Toutes vos données sont effacées immédiatement et définitivement.

Puis-je utiliser l'app sans créer de compte ?

Non. Un compte est nécessaire pour gérer votre quota de vérifications gratuites et vous renvoyer les résultats par email.

L'application fonctionne-t-elle hors ligne ?

Non. Une connexion internet est requise pour envoyer le contenu à analyser à notre intelligence artificielle.
